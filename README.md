# Apex University Website

A responsive university website developed as a web development project.

## Technologies Used

- HTML5
- CSS3
- JavaScript

## Features

- Responsive design
- Navigation bar
- University information
- Courses section
- About section
- Blog section
- Contact section
- Interactive user interface

## Project Purpose

This project was developed to practice front-end web development,
responsive design, UI development, and JavaScript functionality.
